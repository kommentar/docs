## What is Kommentar

In one sentence, Kommentar is a lightweight application that allows you to add comments to your website with ease.

Kommentar is fully open-source and built to be self-hostable first, giving you total control over all your data.


## What is included

Kommentar has 2 main applications:

- Kommentar - The core application. A simple CRUD API for now.
- Admin Console - The administration panel to manage the instance of Kommentar

Being fully open source, there are also the following supporting repositories:
- Docs - The code for the documentation site (this one).
- Website - The code for the public website - a landing page of sorts.
